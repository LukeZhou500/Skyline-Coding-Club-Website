Usaco!

What is USACO? Usaco is an online coding contest with various difficultys, it is a great place for members to try out harder competitive programing topics not offered in school, and train their problem solving skills.

What do we do for USACO? Every other week we do a related codeforces problem, and explore cool coding topics.


Usaco guide is a great place to get started with USACO.


I recommend using USACO IDE if you are just getting started it is a website that is very straightforward and functional.

The CPH extention with VS code is another good option


You can find tons of good problems on Codeforces, along with helpful hints and solutions. The problem set can also be sorted by difficulty and type. They also host competitions very frequently.
